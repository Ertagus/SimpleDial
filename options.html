📞 SimpleDial — Options

ℹ️
SimpleDial only recognizes numbers and opens tel:number. Who answers the call depends on the handler registered in the browser or in the operating system.

Right-clicking a link or a selected number shows the Call entry. The toolbar icon opens tel: with no number, bringing up the phone application as it is.

On the first call the browser asks once for permission to open the associated application. Once granted, it never asks again, on any site.
Number recognition

Regular expression applied to the candidate after removing spaces, dots, hyphens and brackets. Alternatives are separated with |. If it cannot be compiled, the default rules are used.

Test

Type a number as it would appear on a page to see whether it would be recognized with the rule currently set.

tel: protocol handler

Chrome lists at chrome://settings/handlers the web applications allowed to handle tel: and lets you revoke them. If the number is meant to reach a softphone installed on the computer, that association belongs to the operating system and does not appear here.

Toolbar icon

Off by default: clicking the icon opens the phone application straight away. When on, a small panel appears where a number can be typed — useful for numbers that are not on the page.

Call by QR code

Instead of opening the computer's phone application, SimpleDial shows a QR code: point your phone's camera at it to start the call from there. While this is on, the toolbar icon always opens the typing panel, and the QR always uses tel: whatever the dialing protocol below is set to.

Dialing protocol

Scheme handed to the handler registered in the system. tel: is right almost always. Change it if your softphone only answers to another scheme: some clients register for callto: or sip:.
